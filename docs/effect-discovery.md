# 효과 중심 탐색

- 칭호의 **효과로 칭호 찾기**에서는 적용 직위·상황(세력 지도자, 통솔 장수, 태수 등), 효과 적용 범위(해당 인물, 소속 부대·수행원, 소속 군대, 세력 전체 등), 효과 종류를 조합한다. 스킬은 효과 종류·적용 범위·발동 조건으로 찾는다.
- 분류는 번들 데이터의 효과 설명에 명시된 표현을 사용한다. 수치의 유불리나 누락된 대상·상시 여부를 추정하지 않는다. 분류되지 않은 항목은 **미분류·설명 확인**으로 찾는다.
- 선택한 효과나 대상 중 하나만 일치해도 표시한다. 능력을 부여받는 인물과 그 능력의 전투 대상을 구분한다. 조건에 맞는 설명을 먼저 표시하고 강조하며 나머지 효과도 유지한다.
- 검색어는 순서와 관계없이 모두 포함하는 항목을 찾는다. 띄어쓰기 차이를 허용하고 ‘본인 → 해당 인물/자신’, ‘회복 → 치유/재생/충원’ 등 표현을 함께 찾는다.
- 각 효과 필터는 여러 항목을 체크할 수 있다. 같은 필터 안과 서로 다른 필터 사이 모두 OR(하나라도 포함)로 적용한다. 칭호의 능력치 조건도 OR에 포함하며, 검색어는 이 결과를 추가로 좁힌다. ‘전체’는 해당 필터의 선택을 해제한다.
- 칭호·장비 등 검색 목록은 입력창에서 바로 펼쳐진다. 현재 선택은 결과와 별도로 표시되며, 검색하거나 필터를 바꿔도 선택 자체를 변경하지 않는다. 결과 버튼을 누르면 기존 편집 입력과 같은 change 경로를 사용한다.
- 스킬의 기본 오행은 전체다. 노드나 오행을 바꿔도 검색어와 효과 조건은 유지한다. 처음 40개 이후는 더 보기로 계속 확인할 수 있다.
- 장수 목록의 오행과 즐겨찾기는 동시에 적용된다. 해제 버튼은 검색·오행·즐겨찾기를 해제하고 작업 성별은 유지한다.

트레잇·장비 세트에는 현재 효과 원문이 제공되지 않아, 효과 분류를 임의로 붙이지 않는다. 해당 목록은 이름과 포함 항목으로 검색한다.

능력치 선택지는 빈 placeholder를 제외하고, 실제 속성·기본값·최소/최대 범위가 같은 세트를 묶는다. 정사의 `resolve_records`와 연의의 `resolve`는 화면에서 함께 보이지만 생성 시 각 모드의 원본 키를 연결한다. 수치를 수정한 경우에도 모드별 복제 세트를 만든다. 기존 작업의 원본 세트 키는 별칭으로 계속 해석한다.

이미지는 전체 파일 경로·출처와 연령/계절별 그림 구성이 같은 경우만 묶는다. 그림 구성이 다른 동명 항목은 ‘이미지 구성 1/2…’로 구분한다. 기존 이미지 선택과 즐겨찾기 키도 유지한다. 칭호 선택지는 동일 CEO와 동일 효과인 별칭만 합친다.
