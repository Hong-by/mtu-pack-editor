실제 반환 순서로 읽고 쓰도록 수정했으며 원시 스키마는 보존한다.

## 이름 처리

추가 모드 구성에서 기존 장수 이름 수정과 신규 이름 생성 모두 별도 이름 그룹,
표시 순서, 포함된 각 세력과의 연결을 출력한다. 이름과 그룹의 무작위 생성 가중치는
0이며 원본 문화권 이름 그룹을 수정하지 않는다. 고구려 연결을 포함한 출력 검사는
통과했다. 실제 고구려 캠페인에서 빈 이름이 해결되는지는 게임 내 재시험이 필요하다.
기본 구성으로 만든 기존 팩에 추가 모드 호환 자료가 소급 적용되지는 않는다.

## 보존 자료와 검증 경계

현재 RPFM으로 해석할 수 없는 원본은 삭제하거나 다른 스키마로 추측 변환하지 않고
`undecoded_source_tables.json`에 바이트와 오류를 보존한다. 두 구성 모두 109파일:
빈 구형 테이블 104개, DB가 아닌 텍스트 1개, 비어 있지 않은 구형 테이블 4개다.
4개는 `ceo_to_ui_display_junctions`의 ytr/NMC, `ceo_equipped_set_bonuses_to_incident_junctions`의
path_to_unity, `start_pos_character_skills_selection_overrides`의 main campaign 데이터다.
이 네 테이블은 해석·검증 완료로 간주하지 않는다. 캠페인 초기 배치 전체를 재생성하거나
사용자의 모든 추가 모드 조합을 검증한 것도 아니다. 칭호 효과는 실제 CCD를 사용한다.

회귀 검사 129개와 UI 검색/선택 Node 검사 16개 통과. 별도 브라우저에서 고남무의
기존 수정·신규 생성 화면에 `관대한 왕` 및 효과 표시, 두 작업을 별도로 추가하여
`work/optional-ui-korea-test.pack` 저장 완료를 확인했다. 게임 설치 팩은 변경하지 않았다.
