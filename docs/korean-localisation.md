# 한글 패치 명칭

더 결집 지역 및 한글 패치의 번역 1,746개를
`tk_pack_builder/data/gathering_ko.loc.json`에 출처 파일명과 SHA-256과 함께 보관한다.
실행 중 게임 설치 경로를 찾지 않는다. 바닐라·MTU, 190, 한반도 모두 같은 번역을
우선 적용하며 패치에 없는 번역은 해당 구성의 기존 값을 유지한다.

명칭과 설명만 반영한다. CEO 키, 장수 키, 효과 수치, 능력 연결은 변경하지 않는다.
사용자가 지정한 신규 장수 이름·기존 작업·생성 팩은 자동으로 다시 쓰지 않는다.
게임에서 다른 번역 모드를 우선 사용하면 프로그램과 표시명이 다를 수 있다.

하만 칭호는 `3k_ytr_ceo_career_historical_he_man`을 유지하고 `절천야차`로 표시한다.
이전 명칭 `최강자`는 검색 별칭으로 추가하지 않는다.

자료 갱신:

```
python scripts/apply_korean_patch_catalogs.py --pack PATH_TO_KOREAN_PATCH.pack
```

번역을 가져온 후 서버를 다시 시작한다. 목록 캐시는 번역 파일 지문 변경으로 갱신된다.
추가 모드 자료를 다시 번들링한 후에도 같은 스크립트를 실행해 정적 효과 카탈로그를 갱신한다.
Windows 배포 스크립트와 spec에도 번역 파일을 포함했다. 기존 EXE/ZIP은 재빌드하지 않았다.
