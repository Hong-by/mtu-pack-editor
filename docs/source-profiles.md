# 선택형 자료 구성 및 두 장수 기능 검수 (2026-11-28)

## 사용 방법

기본은 바닐라·MTU다. `190 Expanded`, `한반도 (190 포함)`을 선택하고
`선택한 구성 적용`을 누르면 장수·스킬·칭호 목록과 생성 재료, CEO 검증 자료가
함께 전환된다. 한반도를 선택하면 190도 선택되고, 190을 해제하면 한반도도 해제된다.
게임의 모드 설치나 활성화까지 수행하는 기능은 아니다. 제작자의 필수 선행 모드가 필요하다.

작업마다 생성 당시 구성을 보관한다. 다른 구성으로 전환하면 기존 작업을 유지하되
편집과 저장을 보류한다. 같은 이름/키라도 효과가 달라질 수 있으므로 자동 변환하지 않는다.
기존 저장 작업 중 구성 표시가 없는 것은 바닐라·MTU로 취급한다.

## 자료 경계

- `work/internal_materials/vanilla_mtu`: 기존 기본 자료
- `work/internal_materials/190`: 190 본체 → Overhaul Addition → Regions → 한국어 번역
- `work/internal_materials/190-korea`: 위 구성 + Korean Plus 본체
- 190은 Regions CCD, 한반도는 Korean Plus CCD의 실제 CEO/칭호 효과를 사용한다.
- Reskin, BFG, 성능 모드는 이 자료 구성에 포함하지 않는다.
- 실행 시 게임 설치 경로를 찾지 않는다. 유지보수자가 `scripts/bundle_optional_profiles.py --workshop PATH --game GAME_PATH`로 명시적으로 가져온 자료와 일러스트를 배포한다.
- 동일 DB 기본키는 구성 순서로 병합하고, 개별 팩 안에서는 파일명 우선순위를 적용한다.
  실제 사용자의 모든 추가 모드·로드 순서까지 보장하는 검사는 아니다.
- 190의 비 UTF-8 CCD 문자열은 surrogateescape로 원래 바이트를 보존한다.
  UTF-8 DB/Lua에 안전하게 옮길 수 없는 CEO 키는 선택 목록에서 제외한다.
- 충돌하는 염상 템플릿은 격리한다. 한반도의 누락된 patriotic_solidarity 표시 참조와
  해당 능력에 의존하는 부대·수행원 자료도 격리한다. 원본 모드 팩은 수정하지 않는다.
- 각 구성의 `audit.json`에 출처 파일 크기·수정 시각, 제외 키와 행을 기록한다.

## 기존 수정과 신규 생성의 차이

| 경로 | 기존 장수 수정 | 신규 장수 생성 |
| --- | --- | --- |
| UI 작업 | patch_character | clone_character |
| 레시피 | characterPatches | characterCloneRecipes |
| 장수 키 | 기존 키 유지 | 별도 새 키 |
| DB 처리 | 선택한 기존 템플릿/모드별 상세 수정 | 새 템플릿/상세/필요한 연결 복제 |
| 등장 스크립트 | 생성하지 않음 | 캠페인 시작·지연 합류 설정일 때 생성 |
| 칭호·트레잇·장비 | 기존 키를 대상으로 공통 적용 코드 사용 | 새 키를 대상으로 공통 적용 코드 사용 |

신규 생성에서 `frontend_character_ceos`를 복제하던 호출을 제거했다.
이 테이블은 `frontend_characters`를 참조하지만 생성기는 캠페인 템플릿만 만들기 때문에
새 템플릿 키를 그대로 넣으면 존재하지 않는 시작 화면 장수 참조가 된다.
캠페인의 초기 CEO 및 칭호·트레잇·장비 적용 경로는 유지한다.

## 검증과 한계

- 회귀 검사: source_profiles + delta_builder_material_rows + web_app_config, 164개 통과.
- 기존 검색·선택 UI Node 검사 13개 통과.
- 실제 팩 생성/재개봉: 기본·190·한반도의 신규 생성 각각 통과.
- 실제 혼합 팩: 세 구성 모두 기존 조조는 기존 키, 신규 손인 기반 장수는 별도 키로 생성.
  정사·연의 상세 행은 각 2개, 등장 스크립트는 신규 키만 포함, 시작 화면 CEO 행 없음.
- UI: 190/한반도 적용, 필수 모드 선택 연동, 구성 변경 시 작업 보존과 저장 차단 확인.
- UI: 1920/2560 너비의 본문이 화면 하단 안에 들어옴. 1280 너비는 페이지 스크롤 허용.
- 테스트 팩은 `work/`에만 생성했다. 사용자 output/my_hero_patch.pack 및 게임 설치 팩은 변경하지 않았다.

사용자가 보고한 새 캠페인 종료는 190·한반도를 사용하지 않은 구성이다.

시작 화면 CEO 참조 오류 3개는 확인했지만 이것이 종료의 직접 원인이라는 증거는 아직 없다.
03:19:50 스택 파일에는 모듈명만 있어 원인 함수가 식별되지 않았다.
팩 구조 검사 통과를 실제 게임 캠페인 로딩 성공으로 해석하면 안 된다.
